Somo API Documentation

White-label voice AI agent platform for healthcare commerce and patient services.

Base URL

https://api.myskinandcare.com

What is Somo?

Somo is a comprehensive middleware platform that enables healthcare providers to offer voice-powered commerce and patient services through phone calls and mobile applications.

Key Features

  • Voice AI Agent - Natural language conversations via phone calls
  • Healthcare Commerce - Patients can order products/services via voice
  • FHIR Integration - Healthcare data standards (patient records, encounters)
  • Payment Processing - Stripe, Circle wallets, insurance billing
  • Appointment Management - Schedule, confirm, and manage appointments
  • EHR Integration - Connect to Epic, 1upHealth, and other EHR systems

Quick Start

  1. Sign up for an account at https://api.myskinandcare.com
  2. Complete email verification and accept terms of service
  3. Add a payment method (required, but no charges until free credits are used)
  4. Receive 100 free voice minutes and 1,000 free API requests/month
  5. Get your Retell Agent ID from your Profile (GET /api/customers/me)
  6. Create API keys in your Profile (for REST API calls)
  7. Integrate Retell SDK into your mobile app (Flutter/iOS/Android)
  8. Start voice calls - Somo handles everything automatically

Authentication

Most API endpoints require authentication using API keys or Bearer tokens.

Note: To create and manage your API keys, visit your Profile page.

API Key Authentication

Include your API key in the request headers:

Authorization: Bearer your-api-key-here
# OR
X-API-Key: your-api-key-here

Example Request

fetch('https://api.myskinandcare.com/voice/products/search', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer your-api-key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    merchant_id: 'your-clinic-id',
    query: 'vitamin D'
  })
});

Endpoints for voice commerce and patient interactions.

Search for products/services available for voice ordering.

Create a checkout session for a voice order.

Request Body

{
  "merchant_id": "your-clinic-id",
  "product_id": "prod_123",
  "customer_phone": "+15555551234",

Response

{
  "success": true,
  "checkout_id": "checkout_xxx",
  "amount": 29.99,
  "payment_token": "token_xxx"

POST /voice/incoming

Twilio webhook endpoint for incoming voice calls. This is automatically handled by Twilio when a patient calls your number.

Webhooks

Receive real-time events from the platform.

Setting Up Webhooks

Configure your webhook URL in your clinic settings. We'll send POST requests to your endpoint when events occur.

Webhook Events

  • checkout.completed - Payment successfully processed
  • checkout.failed - Payment failed
  • appointment.created - New appointment scheduled
  • appointment.confirmed - Appointment confirmed
  • patient.created - New patient registered

Webhook Payload Example

  }

WebSocket for Real-Time Voice

For in-app voice calls via Retell SDK, the WebSocket connection is automatically handled by Retell. Your Retell agent is configured to connect to:

wss://api.myskinandcare.com/retell-llm

Note: You don't need to manually connect to this WebSocket. When you initialize Retell SDK with your retell_agent_id, Retell automatically routes calls to Somo's WebSocket handler.

Mobile Integration

Integrate Somo voice AI agent into your Flutter, iOS, or Android mobile app using Retell SDK.

Quick Start

  1. Sign up and get your retell_agent_id from your Profile
  2. Install Retell SDK for Flutter/iOS/Android
  3. Initialize SDK with your agent ID and customer_id
  4. Start voice calls - Somo handles everything automatically

Step 1: Get Your Integration Credentials

First, retrieve your Retell Agent ID and Customer ID from your profile:

GET /api/customers/me

Get your customer profile including Retell Agent ID.

Response

{
  "success": true,
  "customer": {
    "id": "customer_abc123",
    "email": "your@email.com",
    "company_name": "Your Company",
    "retell_agent_id": "agent_xyz789",
    "retell_agent_status": "active"
    }
}

Critical Fields:

  • customer.id - Your Customer ID (pass in dynamic_variables)
  • retell_agent_id - Your Retell Agent ID (use in SDK initialization)

Step 2: Flutter Integration (Retell SDK)

Integrate voice AI into your Flutter app:

1. Install Retell Flutter SDK

# pubspec.yaml
dependencies:
  retell_sdk: ^latest_version

2. Initialize Retell SDK

import 'package:retell_sdk/retell_sdk.dart';

// Get credentials from your profile API
final customerResponse = await http.get(
  Uri.parse('https://api.myskinandcare.com/api/customers/me'),
  headers: {
    'Cookie': 'customer_session=your_session_cookie',
  },
);

final customer = jsonDecode(customerResponse.body)['customer'];
final retellAgentId = customer['retell_agent_id'];
final customerId = customer['id'];

// Initialize Retell SDK
final retellConfig = RetellConfig(
  agentId: retellAgentId, // From Step 1
  dynamicVariables: {
    'customer_id': customerId, // CRITICAL: Must pass customer_id
    'patient_id': currentPatient.id, // Optional: Current patient context
    'context': 'appointment_booking', // Optional: Call context
  },
  metadata: {
    'customer_id': customerId, // Backup: Also in metadata
    'source': 'flutter_app',
  },
);

// Start voice call
Retell.startCall(config: retellConfig);

⚠️ Important Requirements

  • MUST pass customer_id in dynamic_variables for proper tracking
  • Use retell_agent_id from your customer profile (each customer gets their own agent)
  • Voice agent automatically connects to Somo WebSocket: wss://api.myskinandcare.com/retell-llm

Step 3: iOS Integration (Swift)

For iOS apps using Retell iOS SDK:

import RetellSDK

// Get credentials from your profile API
let url = URL(string: "https://api.myskinandcare.com/api/customers/me")!
var request = URLRequest(url: url)
request.setValue("customer_session=your_session_cookie", forHTTPHeaderField: "Cookie")

URLSession.shared.dataTask(with: request) { data, response, error in
    guard let data = data,
          let json = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
          let customer = json["customer"] as? [String: Any],
          let retellAgentId = customer["retell_agent_id"] as? String,
          let customerId = customer["id"] as? String else {
        return
    }
    
    // Initialize Retell SDK
    let config = RetellConfig(
        agentId: retellAgentId,
        dynamicVariables: [
            "customer_id": customerId, // CRITICAL
            "patient_id": currentPatient.id, // Optional
            "context": "appointment_booking" // Optional
        ],
        metadata: [
            "customer_id": customerId, // Backup
            "source": "ios_app"
        ]
    )
    
    // Start voice call
    Retell.startCall(config: config)
}.resume()

Step 4: Android Integration (Kotlin)

For Android apps using Retell Android SDK:

import com.retellai.retellsdk.RetellSDK
import com.retellai.retellsdk.models.RetellConfig

// Get credentials from your profile API
val url = "https://api.myskinandcare.com/api/customers/me"
val client = OkHttpClient()
val request = Request.Builder()
    .url(url)
    .addHeader("Cookie", "customer_session=your_session_cookie")
    .build()

client.newCall(request).enqueue(object : Callback {
    override fun onResponse(call: Call, response: Response) {
        val json = JSONObject(response.body?.string() ?: "")
        val customer = json.getJSONObject("customer")
        val retellAgentId = customer.getString("retell_agent_id")
        val customerId = customer.getString("id")
        
        // Initialize Retell SDK
        val config = RetellConfig(
            agentId = retellAgentId,
            dynamicVariables = mapOf(
                "customer_id" to customerId, // CRITICAL
                "patient_id" to currentPatient.id, // Optional
                "context" to "appointment_booking" // Optional
            ),
            metadata = mapOf(
                "customer_id" to customerId, // Backup
                "source" to "android_app"
            )
        )
        
        // Start voice call
        RetellSDK.startCall(context, config)
    }
    
    override fun onFailure(call: Call, e: IOException) {
        // Handle error
    }
})

How It Works

When your mobile app initiates a voice call:

  1. Retell SDK captures audio and processes speech-to-text
  2. Retell AI routes the call to Somo WebSocket: wss://api.myskinandcare.com/retell-llm
  3. Somo WebSocket Handler extracts customer_id from dynamic_variables
  4. Function Calls are executed based on user intent:
    • schedule_appointment → EHR integration
    • collect_insurance → Insurance eligibility checks
    • process_payment → Payment processing
    • get_patient_claims → Insurance claims retrieval
  5. Usage Tracking automatically tracks voice minutes and deducts from your credits

Available Voice Functions

Your voice agent can perform these healthcare functions:

  • Appointment Scheduling - Schedule, confirm, reschedule, or cancel appointments
  • Insurance Management - Collect insurance info, check eligibility, submit claims
  • Payment Processing - Process payments via Stripe
  • Patient Data Access - Retrieve patient records via EHR integration

Usage Tracking & Billing

Somo automatically tracks both voice call minutes and API requests:

  • Voice Calls: Tracked by call duration (minutes). 100 free minutes included.
  • API Requests: Tracked per request. 1,000 free requests per month.
  • Overage Billing: $0.05/min for voice, $0.01/1k for API requests beyond free tier.

Track your usage and view billing information:

GET /api/credits/balance

Get your current credit balance for voice minutes (free and paid).

GET /api/customers/me/credits-and-billing

Get comprehensive billing summary including voice minutes, API requests, current month usage, and invoice history.

GET /api/credits/usage

GET /api/customers/me/invoices

View your invoice history.

Pricing & Billing

Somo offers transparent, usage-based pricing with generous free credits to get you started.

Free Credits

New customers receive free credits upon account activation:

  • Voice Call Minutes: 100 free minutes for voice calls (one-time allocation)
  • API Requests: 1,000 free API requests per month (resets monthly)

Free credits are allocated when you accept the Terms of Service. No payment method required to use free credits.

Usage-Based Pricing

After free credits are exhausted, usage is billed as follows:

Service Free Tier Overage Pricing
Voice Calls 100 minutes (one-time) $0.05 per minute
API Requests 1,000 requests/month $0.01 per 1,000 requests

Payment Method Requirement

A valid payment method must be on file before accessing the Service. No charges will be made until your free credits are exhausted. Your payment method will be charged monthly for usage beyond free credits.

Billing & Invoicing

  • Usage is tracked per calendar month
  • Invoices are generated monthly for overage usage (beyond free credits)
  • Payment is due within 15 days of invoice date
  • View your usage and billing at /profile
